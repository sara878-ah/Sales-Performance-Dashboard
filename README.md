# Sales Performance Dashboard | Power BI

## Project Overview

This project presents an interactive Sales Performance Dashboard built using Power BI. The dashboard provides insights into sales performance, product performance, store performance, and payment methods to support data-driven decision-making.

## Key Features

* Total Sales Analysis
* Total Quantity Analysis
* Average Order Value (AOV)
* Product Performance Analysis
* Store Performance Analysis
* Payment Method Analysis
* Interactive Filters and Slicers

## Tools Used

* Power BI
* Power Query
* DAX

## Dashboard Insights

* Identified top-performing products based on sales.
* Compared sales performance across different store locations.
* Analyzed customer purchasing behavior through AOV.
* Evaluated payment method distribution.
